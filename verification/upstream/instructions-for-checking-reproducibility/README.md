For any source code that correctly implements the pseudocode in our paper, the following key metrics should be consistent.
The values produced by our original implementations are shown in the table below.

| Lemma A.2 | Size of $\mathcal{R}^{*-\mathcal{D}}$                                               | 671            |
| Lemma A.2 | Maximum amount of charge of the combined rules in $\mathcal{R}^{*-\mathcal{D}}$     | 5              |

| Lemma A.3 | Number of bad cartwheels with tail ranges whose center degree $8$                   | 728            |

| Lemma A.3 | Number of cartwheels whose center degree $8$ enumerated by `enumPossibleBadWheels`  | 6790           |
| Lemma A.3 | Number of cartwheels whose center degree $9$ enumerated by `enumPossibleBadWheels`  | 3285           |

Although this validation does not guarantee 100% correctness, the consistency of these key values suggests that there are no major discrepancies from our original implementation. This holds regardless of whether the source code is generated by a human or by an LLM.

## Instructions to write source code with/without LLM
This repository contains a Markdown file, `instructions.md`, intended to assist those who wish to implement the algorithms described in our paper. The file is intended for people interested in implementing the algorithms, either by hand or with the assistance of LLMs.
When using LLMs, we recommend instructing the LLM not to access the repository containing the original source code.

We have utilized three LLMs (Google Gemini Deep Think, Claude Code, and OpenAI Codex) to generate source code relevant to this paper. 
For the source code generated by these three LLMs, we confirmed that the key values above match the expected values. 
The source code generated by these LLMs is available in the following repositories:
